# Photographs

Drop files straight into this folder. The names matter: each one maps to an
exact slot on the site, so a correctly named file needs no other work.

The full list, with the target size and a description of each shot, is in
`3 Needs your input/Checklist.md` under **Photographs**. There are 55 slots.

## The rules

**Use the exact filename.** `member-keerthana.jpg`, not `Keerthana.JPG` or
`keerthana_photo.jpg`. Lower case, hyphens, no spaces.

**Match the shape, not the pixels.** The checklist gives a target size such
as `640x800`. Anything larger with the same proportions is better, not worse.
A 1280x1600 photo in a 640x800 slot is ideal.

**File types.** `.jpg` for photographs, `.png` for logos with a transparent
background. Keep the extension the checklist asks for.

**Portraits should be consistent.** The roster reads as one team when the
crop and the distance are the same across all nineteen. Head and shoulders,
same rough framing, is enough. They do not need a studio.

**Sponsor logos** work best as light-on-dark or plain white on transparency,
because they sit on a near-black page. If you only have a dark logo on white,
send it anyway and it can be inverted.

## What happens if a photo is missing

Nothing breaks. Every slot currently holds a labelled placeholder that names
the shot it is waiting for, so the layout is already correct and you can add
photographs one at a time in any order.
