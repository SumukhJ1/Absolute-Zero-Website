# Open Access documents

The Open Access page publishes the team's engineering notebooks, pit designs
and guides for other FIRST teams. Drop the PDFs into this folder.

Sixteen items are listed on the page right now. Each one shows an honest
"file pending" label instead of a broken link until a file is attached, so
you can add them in any order.

## The list

The full set is in `3 Needs your input/Checklist.md` under **Open Access
documents**, grouped by shelf:

- **Engineering notebooks** — DECODE, POWERPLAY, SKYSTONE, ROVER RUCKUS
- **Pit designs** — layout drawings, parts list
- **Build guides** — drivetrain, wiring, prototyping
- **Programming guides** — OnBot Java, repeatable autonomous, telemetry
- **Outreach materials** — library run sheet, build challenge, closing script

## Naming

Anything readable is fine here, because these get uploaded to the WordPress
media library and linked by hand rather than matched by filename. Something
like `decode-2025-26-engineering-notebook.pdf` is plenty.

## How they get onto the site

In WordPress: **Open Access library** in the sidebar, open the item, and paste
the media URL into the **File or link** field. The "file pending" label turns
into a working download.

If a document on the list does not exist, or you would rather not publish it,
delete that item in WordPress and the shelf closes up around it.

## One thing to check first

These are public. Anything with a student's full name, a home address, a phone
number or a school ID in it should be redacted before it goes up.
